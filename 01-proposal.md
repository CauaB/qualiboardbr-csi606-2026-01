### Resumo

O QualiBoardBR é uma aplicação voltada para empresas que gerenciam múltiplos projetos de software simultaneamente. O sistema permite centralizar o registro e o acompanhamento de falhas técnicas (bugs), garantindo que cada ocorrência esteja devidamente vinculada ao seu respectivo projeto. O objetivo principal é facilitar a organização das equipes, oferecendo uma visão clara das pendências e da urgência de cada correção, do cadastro à manutenção dos dados.

### 1. Tema

O trabalho final tem como tema o desenvolvimento do QualiBoardBR, um Sistema de Controle de Bugs com foco em gestão multi-projeto.

### 2. Escopo

Este projeto terá as seguintes funcionalidades:

- **Gestão de Projetos:** Cadastro, listagem, edição e exclusão de diferentes projetos da empresa (ex: "Sistema de Vendas", "App Mobile", "Portal do Cliente").
- **Gerenciamento Completo de Bugs (CRUD):** - *Registro:* Ao cadastrar uma falha, será obrigatório selecionar o projeto correspondente, informar título, descrição, passos para reproduzir e prioridade (Alta, Média ou Baixa).
  - *Manutenção:* Possibilidade de editar os detalhes de um bug ou excluí-lo do sistema.
- **Controle de Status:** Opção para atualizar a situação da falha conforme o progresso da equipe (ex: Aberto, Em Correção, Corrigido).
- **Filtros e Visualização:** Uma tela principal que permite filtrar os bugs por projeto, facilitando a visualização do que é relevante para cada equipe no momento.

### 3. Restrições

Neste trabalho não serão considerados:
- Comunicação em tempo real (como chat embutido) entre os usuários.
- Geração de relatórios analíticos complexos em PDF nesta primeira versão.

### 4. Protótipo

Protótipos para as páginas (dashboard de projetos, listagem de bugs, tela de cadastro/edição e painel de filtros).
